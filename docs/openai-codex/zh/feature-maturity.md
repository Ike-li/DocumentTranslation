# 功能成熟度

部分 Codex 功能会标注成熟度等级，以便你了解每项功能的可靠程度、可能发生的变化以及预期的支持水平。

| 成熟度 | 含义 | 指导建议 |
| ----------------- | ------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| 开发中 | 尚未准备好投入使用。 | 请勿使用。 |
| 实验性 | 不稳定，OpenAI 可能会移除或更改该功能。 | 使用风险自负。 |
| Beta | 已准备好进行广泛测试；大部分功能已完善，但某些方面可能会根据用户反馈进行调整。 | 适用于大多数评估和试点场景；预期会有小幅变更。 |
| 稳定 | 完全受支持、有文档记录并已准备好广泛使用；行为和配置将保持长期一致。 | 可安全用于生产环境；移除通常会经过弃用流程。 |
