# Codex Web

Codex 是 OpenAI 的编码代理，能够读取、编辑和运行代码。它帮助你更快地构建、修复 bug 以及理解陌生的代码。通过 Codex 云端功能，Codex 可以使用自己的云环境在后台处理任务（包括并行执行）。

## Codex Web 设置

前往 [Codex](https://chatgpt.com/codex) 并连接你的 GitHub 账户。这样 Codex 就能访问你仓库中的代码，并根据其工作成果创建拉取请求。

你的 Plus、Pro、Business、Edu 或 Enterprise 套餐已包含 Codex。了解更多关于[包含内容](https://developers.openai.com/codex/pricing)的信息。部分 Enterprise 工作空间可能需要[管理员设置](https://developers.openai.com/codex/enterprise/admin-setup)后才能访问 Codex。

---

## 使用 Codex Web

### 了解提示词编写

编写更清晰的提示词，添加约束条件，并选择适当的详细程度以获得更好的结果。

### 常见工作流

从经过验证的模式开始，委派任务、审查变更，并将结果转化为拉取请求。

### 配置环境

选择 Codex 在云端运行任务时应使用的仓库、设置步骤和工具。

### 从 IDE 扩展委派工作

从编辑器启动云端任务，然后监控进度并将生成的差异应用到本地。

### 从 GitHub 委派

在议题和拉取请求中标记 `@codex`，即可直接从 GitHub 启动任务并提出变更建议。

### 控制网络访问

决定 Codex 是否可以从云环境访问公共互联网，以及何时启用该功能。
