# 管理会话

> 命名、恢复、分支和切换 Claude Code 对话。涵盖 `--continue`、`--resume`、`--from-pr`、`/resume` 选择器、会话命名以及会话记录的存储位置。

会话是与项目目录关联的已保存对话。Claude Code 在你工作时将其存储在本地，因此你可以从上次中断的地方恢复、创建分支尝试不同的方法，或在任务之间切换。

[桌面应用](/zh/desktop#work-in-parallel-with-sessions)、[Claude Code 网页版](/zh/claude-code-on-the-web) 和 [VS Code 扩展](/zh/vs-code#resume-past-conversations) 各自维护独立的会话历史记录。本页面涵盖 CLI 部分：

* [恢复](#恢复会话)之前的对话（通过标志、名称或 PR）
* [命名](#命名会话)会话以便后续查找
* [浏览](#使用会话选择器)会话（使用 `/resume` 选择器）
* [分支](#分支会话)对话以尝试不同的方法
* [导出](#导出和定位会话数据)会话记录并在磁盘上找到它们

## 恢复会话

会话在你工作时会持续保存到[本地会话记录文件](#导出和定位会话数据)，因此你可以在退出或执行 `/clear` 后返回到之前的会话。使用以下入口：

| 命令                        | 功能                                                               |
| :-------------------------- | :----------------------------------------------------------------- |
| `claude --continue`         | 恢复当前目录中最近的会话                                           |
| `claude --resume`           | 打开[会话选择器](#使用会话选择器)                                  |
| `claude --resume <name>`    | 直接恢复指定名称的会话                                             |
| `claude --from-pr <number>` | 恢复与该 Pull Request 关联的会话                                   |
| `/resume`                   | 在活跃会话中切换到另一个对话                                       |

使用 [`claude -p`](/zh/headless) 或 [Agent SDK](/zh/agent-sdk/overview) 创建的会话不会出现在会话选择器中，但你仍然可以通过将会话 ID 传递给 `claude --resume <session-id>` 来恢复。

### 会话选择器的查找范围

会话按项目目录存储。默认情况下，会话选择器显示当前工作树中的交互式会话，以及在其他位置启动但通过 `/add-dir` 添加了当前目录的会话。使用 `Ctrl+W` 可扩展到仓库的所有工作树，使用 `Ctrl+A` 可扩展到本机上的所有项目。

从同一仓库的其他工作树中选择会话将在原位置恢复。从无关项目中选择会话则会将 `cd` 和恢复命令复制到你的剪贴板。

按名称恢复会在当前仓库及其工作树中查找。两种形式都会查找精确匹配并直接恢复，即使它位于不同的工作树中：

| 命令                     | 精确匹配       | 名称歧义                                                                    |
| :----------------------- | :------------- | :-------------------------------------------------------------------------- |
| `claude --resume <name>` | 直接恢复       | 打开会话选择器，名称预填为搜索词                                            |
| `/resume <name>`         | 直接恢复       | 报告错误；不带参数运行 `/resume` 打开会话选择器                             |

## 命名会话

为会话设置描述性名称，以便在会话选择器中找到它们并通过名称恢复。当你同时处理多个任务时，这一点尤为重要。

| 时机                    | 如何设置名称                                                                                                                                                   |
| :---------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 启动时                  | `claude -n auth-refactor`                                                                                                                                      |
| 会话期间                | `/rename auth-refactor`。名称也会显示在提示栏中                                                                                                                 |
| 从会话选择器中          | 高亮会话并按 `Ctrl+R`                                                                                                                                          |
| 接受计划时              | 在[计划模式](/zh/permission-modes#analyze-before-you-edit-with-plan-mode)中接受计划会根据计划内容命名会话，除非你已经设置了名称                                   |

命名会话后，使用 `claude --resume <name>` 或 `/resume <name>` 返回。有关跨工作树的名称解析行为，请参阅[恢复会话](#恢复会话)。

## 使用会话选择器

在会话中运行 `/resume`，或不带参数运行 `claude --resume`，打开交互式会话选择器。使用以下快捷键导航、搜索和扩展列表：

| 快捷键                                              | 操作                                                                                                                                                           |
| :-------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `↑` / `↓`                                          | 在会话之间导航                                                                                                                                                 |
| `→` / `←`                                          | 展开或折叠分组的会话                                                                                                                                           |
| `Enter`                                             | 恢复高亮的会话                                                                                                                                                 |
| `Space`                                             | 预览会话内容。在不捕获 `Space` 为粘贴的终端上也可以使用 `Ctrl+V`                                                                                               |
| `Ctrl+R`                                            | 重命名高亮的会话                                                                                                                                               |
| `/` 或 `Space` 以外的任何可打印字符                 | 进入搜索模式并过滤会话。粘贴 GitHub、GitHub Enterprise、GitLab 或 Bitbucket 的 Pull Request 或 Merge Request URL 可查找创建该请求的会话                        |
| `Ctrl+A`                                            | 显示本机上所有项目的会话。再次按下返回当前仓库                                                                                                                 |
| `Ctrl+W`                                            | 显示当前仓库所有工作树的会话。再次按下返回当前工作树。仅在多工作树仓库中显示                                                                                   |
| `Ctrl+B`                                            | 过滤为当前 Git 分支的会话。再次按下显示所有分支                                                                                                                |
| `Esc`                                               | 退出会话选择器或搜索模式                                                                                                                                       |

每一行显示会话名称（如果已设置），否则显示对话摘要或第一个提示词，以及距上次活动的时间、消息数量和 Git 分支。使用 `Ctrl+A` 扩展到所有项目后会显示项目路径。

使用 `/branch`、`/rewind` 或 `--fork-session` 创建的分叉会话会分组在其根会话下。按 `→` 展开分组。

## 分支会话

分支会创建当前对话的副本并切换到该副本，保留原始会话不变。用它来尝试不同的方法，而不会丢失你之前的进度。

在会话内部，运行 `/branch` 并可选地指定名称：

```text
/branch try-streaming-approach
```

从命令行，将 `--continue` 或 `--resume` 与 `--fork-session` 组合使用：

```bash
claude --continue --fork-session
```

原始会话保持不变，仍可在会话选择器中找到。`/branch` 确认信息会打印两个会话 ID：你当前所在的新分支和原始会话。要返回原始会话，将其 ID 传递给 `/resume`、使用会话选择器或运行 `/resume <original-name>`。你以"允许本次会话"批准的权限不会延续到新分支。如果你在两个终端中恢复同一会话而不进行分支，来自两个终端的消息会交错写入同一会话记录。

有关单个会话内基于检查点的回退，请参阅[检查点](/zh/checkpointing)。

## 在会话中管理上下文

以下命令控制上下文窗口中的内容，无需离开会话：

* **`/clear`**：清空上下文重新开始。之前的对话会被保存并可恢复
* **`/compact [instructions]`**：用摘要替换历史记录，可选择性地专注于你指定的内容
* **`/context`**：显示当前占用上下文的内容

有关压缩如何与 CLAUDE.md、技能和规则交互，请参阅[上下文窗口指南](/zh/context-window)。关于何时清除与压缩的策略，请参阅[最佳实践](/zh/best-practices#manage-your-session)。

## 导出和定位会话数据

运行 `/export` 可将当前对话复制到剪贴板或保存为纯文本文件，消息和工具输出会渲染为可读文本。传递文件名可直接写入该文件。

会话记录以 JSONL 格式存储在 `~/.claude/projects/<project>/<session-id>.jsonl`，其中 `<project>` 派生自你的工作目录路径。每行是一个 JSON 对象，对应一条消息、工具使用或元数据条目。要将会话存储在 `~/.claude` 以外的位置，请设置 [`CLAUDE_CONFIG_DIR`](/zh/env-vars)。这些本地文件默认在 30 天后删除；可通过 [`cleanupPeriodDays`](/zh/settings#available-settings) 修改此设置。

要完全禁止写入会话记录，请设置 [`CLAUDE_CODE_SKIP_PROMPT_HISTORY`](/zh/env-vars)，或在非交互模式下使用 `--no-session-persistence`。
