# 环境变量

> 控制 Claude Code 行为的环境变量参考。

环境变量可以控制 Claude Code 的行为，例如模型选择、身份验证、请求路由和功能开关。许多相同的行为也可以通过[设置文件](/zh/settings)字段、[CLI 标志](/zh/cli-reference)或会话内命令（如 `/model`）来配置。

本页涵盖如何：

* [设置环境变量](#设置环境变量)（在 shell 或设置文件中）
* [检查优先级](#优先级)（当同一行为有多种设置方式时）
* [查阅 Claude Code 读取的变量](#变量)

## 设置环境变量

在 shell 中设置的变量仅在该终端会话中有效，而设置文件中的变量会在每次运行 `claude` 时生效。

### 在 shell 中设置

在启动 `claude` 之前设置变量：

**macOS、Linux、WSL**

```bash
export API_TIMEOUT_MS="1200000"
claude
```

要在每次会话中都设置该变量，请将 `export` 行添加到 `~/.bashrc`、`~/.zshrc` 或 shell 的配置文件中。

**Windows PowerShell**

```powershell
$env:API_TIMEOUT_MS = "1200000"
claude
```

要在每次会话中都设置该变量，请运行 `[Environment]::SetEnvironmentVariable("API_TIMEOUT_MS", "1200000", "User")` 并打开新终端。

**Windows CMD**

```batch
set API_TIMEOUT_MS=1200000
claude
```

要在每次会话中都设置该变量，请运行 `setx API_TIMEOUT_MS "1200000"` 并打开新终端。

### 在设置文件中添加

在 `settings.json` 文件的 `env` 键下添加变量。Claude Code 在启动时直接从文件读取这些变量，因此无论以何种方式启动 `claude` 都会生效。

```json ~/.claude/settings.json
{
  "env": {
    "API_TIMEOUT_MS": "1200000",
    "BASH_DEFAULT_TIMEOUT_MS": "300000"
  }
}
```

你选择的文件决定了变量的作用范围：

| 文件                          | 适用范围                                                   |
| :---------------------------- | :----------------------------------------------------------- |
| `~/.claude/settings.json`     | 你本人，在所有项目中                                        |
| `.claude/settings.json`       | 所有参与项目的人员，纳入版本控制                             |
| `.claude/settings.local.json` | 仅你本人在当前项目中，不纳入版本控制                         |
| 托管设置                       | 组织中的所有成员，由管理员部署                               |

详见[设置文件](/zh/settings#settings-files)了解各文件的位置，以及[设置优先级](/zh/settings#settings-precedence)了解多个文件设置同一变量时的组合规则。

## 优先级

当同一行为同时有环境变量和设置字段时，环境变量优先。例如，`ANTHROPIC_MODEL` 覆盖 `model` 设置，`CLAUDE_CODE_AUTO_CONNECT_IDE` 覆盖 `autoConnectIde`。当环境变量未设置时，使用设置字段。

环境变量与 CLI 标志和会话内命令的交互方式因功能而异：`--model` 和 `/model` 覆盖 `ANTHROPIC_MODEL`，而 `CLAUDE_CODE_EFFORT_LEVEL` 覆盖 `/effort`。当变量与其他配置源存在交互时，其在[变量](#变量)列表中的行会说明优先级或链接到相关文档页面。

Claude Code 在启动时读取环境变量，因此更改将在下次启动 `claude` 时生效。
