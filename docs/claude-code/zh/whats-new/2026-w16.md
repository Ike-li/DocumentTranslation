# Week 16 · 2026 年 4 月 13–17 日

> Claude Opus 4.7 引入了新的 xhigh 努力级别、Claude Code on the web 上的 Routines、在 Claude 需要你时通知手机的移动端推送通知、显示是什么在推高用量限额的 /usage 细分，以及取代捆绑 JavaScript 的原生二进制。

  <p className="digest-feature-lede">Anthropic 迄今最强的编码模型，现已成为 Max 与 Team Premium 的默认模型，并通过 <code>/model</code> 在其他场景可用。它新增了 <code>xhigh</code> 努力级别，介于 <code>high</code> 和 <code>max</code> 之间：在大多数编码与 Agent 任务上表现最佳，并在你首次切换到 4.7 时作为默认级别启用。<code>/effort</code> 现在在不带参数调用时会打开一个交互式方向键滑块，无需记住级别名称即可在智能与速度之间调节。</p>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">原生二进制</span>
    <span className="digest-feature-pill">v2.1.113</span>
  </div>

  <p className="digest-feature-lede"><code>claude</code> CLI 现在会启动每个平台的原生二进制，而不是捆绑的 JavaScript，因此安装的 <code>claude</code> 命令不再调用 Node。npm 包通过可选依赖（如 <code>@anthropic-ai/claude-code-darwin-arm64</code>）拉取对应的二进制，所以你的安装命令无需更改。独立安装包此前已经分发该二进制；npm 现在与之保持一致。</p>

  <p className="digest-feature-try">升级并查看你正在运行的版本：</p>

  ```bash
  claude update
  claude --version
  ```

  <a className="digest-feature-link" href="/docs/en/setup">安装指南</a>
</div>

  <div className="digest-wins-grid">
    <div>新增 <a href="/docs/en/ultrareview"><code>/ultrareview</code></a>：在云端使用并行多 Agent 分析与对抗式批判通道进行全面代码评审。直接运行可评审当前分支，或运行 <code>/ultrareview &lt;PR#></code> 评审指定 PR</div>
    <div><a href="/docs/en/permission-modes#eliminate-prompts-with-auto-mode">Auto 模式</a>现已对使用 Opus 4.7 的 Max 订阅者开放，且不再需要 <code>--enable-auto-mode</code> 标志</div>
    <div><a href="/docs/en/interactive-mode#session-recap">会话摘要</a>会用一行总结你离开期间发生的事情；按需运行 <code>/recap</code>，或在 <code>/config</code> 中关闭</div>
    <div>新增 <code>/tui</code> 命令以及 <code>tui</code> 设置，可在对话中切换经典渲染与无闪烁渲染；focus 视图从 <code>Ctrl+O</code> 移至单独的 <code>/focus</code> 命令</div>
    <div>插件可以通过顶层 <code>monitors</code> manifest 键提供后台 watcher，会话开始或调用 skill 时自动启用</div>
    <div><code>/theme</code> 中新增 "Auto (match terminal)" 选项，跟随终端的深色/浅色模式</div>
    <div><code>/fewer-permission-prompts</code> 会扫描你的对话记录，找出常见的只读 Bash 与 MCP 调用，并为 <code>.claude/settings.json</code> 提议 allowlist</div>
    <div>Claude 现在可以通过 Skill 工具发现并运行内置命令，例如 <code>/init</code>、<code>/review</code> 与 <code>/security-review</code></div>
    <div><code>PreCompact</code> 钩子可以通过退出码 2 或返回 <code>{"{"}"decision":"block"{"}"}</code> 来阻止压缩</div>
    <div><code>ENABLE\_PROMPT\_CACHING\_1H</code> 让 API 密钥、Bedrock、Vertex 与 Foundry 用户可启用 1 小时的提示词缓存 TTL</div>
    <div><code>sandbox.network.deniedDomains</code> 设置可在更宽泛的 <code>allowedDomains</code> 通配符中排除特定域名</div>
    <div><code>/undo</code> 现在是 <code>/rewind</code> 的别名，<code>/proactive</code> 是 <code>/loop</code> 的别名</div>
    <div>更严格的 Bash 权限：deny 规则现在能穿透 <code>env</code>/<code>sudo</code>/<code>watch</code> 包装匹配，<code>Bash(find:\*)</code> 的 allow 规则不再自动放行 <code>-exec</code> 或 <code>-delete</code></div>
