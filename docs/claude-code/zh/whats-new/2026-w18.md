# 第 18 周 · 2026 年 4 月 27 日 – 5 月 1 日

> Claude Code 在 Windows 上无需 Git Bash 即可运行，`claude auth login` 在浏览器回调无法访问 localhost 时接受粘贴的 OAuth 代码，`claude project purge` 可清理项目的本地状态，将 PR URL 粘贴到 /resume 可找到创建该 PR 的会话。

  <div className="digest-feature-header">
    <span className="digest-feature-title">无需浏览器回调即可登录</span>
    <span className="digest-feature-pill">v2.1.126</span>
  </div>

  <p className="digest-feature-lede"><code>claude auth login</code> 现在支持在浏览器回调无法访问 localhost 时，将 OAuth 代码直接粘贴到终端中。这适用于 WSL2、SSH 会话和容器等重定向到本地端口无法工作的场景。此版本还修复了在慢速或代理连接以及仅支持 IPv6 的 devcontainer 中的登录超时问题。</p>

  <p className="digest-feature-try">登录，然后粘贴浏览器中的代码：</p>

  ```bash
  claude auth login
  ```

</div>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">claude project purge</span>
    <span className="digest-feature-pill">v2.1.126</span>
  </div>

  <p className="digest-feature-lede">删除项目的所有 Claude Code 状态：对话记录、任务、文件历史以及项目的配置条目。支持 <code>--dry-run</code> 预览，<code>-y</code>/<code>--yes</code> 跳过确认，<code>-i</code>/<code>--interactive</code> 交互式选择，以及 <code>--all</code> 清除所有项目。</p>

  <p className="digest-feature-try">预览将要删除的内容：</p>

  ```bash
  claude project purge --dry-run
  ```

  <p className="digest-feature-try">然后实际执行：</p>

  ```bash
  claude project purge
  ```

  <a className="digest-feature-link" href="/docs/en/cli-reference">CLI 参考</a>
</div>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">通过 PR URL 恢复会话</span>
    <span className="digest-feature-pill">v2.1.122</span>
  </div>

  <p className="digest-feature-lede">当你使用 <code>gh pr create</code> 创建拉取请求时，Claude Code 会将其链接到产生它的会话。现在你可以仅通过 PR URL 返回该会话，无需记住会话名称。</p>

  <p className="digest-feature-try">打开会话选择器：</p>

  ```text Claude Code
  > /resume
  ```

  <p className="digest-feature-try">将 PR URL 粘贴到选择器中。粘贴的第一个字符会进入搜索模式，列表会筛选出创建该 PR 的会话。按 Enter 恢复该会话。GitHub、GitHub Enterprise、GitLab 和 Bitbucket 的拉取请求与合并请求 URL 均可使用。</p>

  ```text Claude Code
  https://github.com/your-org/your-repo/pull/1234
  ```

  <p className="digest-feature-try">要跳过选择器，可在命令行中传入 PR 编号：</p>

  ```bash
  claude --from-pr 1234
  ```

  <a className="digest-feature-link" href="/docs/en/sessions#use-the-session-picker">会话：使用会话选择器</a>
</div>

<div className="digest-wins">
  <p className="digest-wins-title">其他改进</p>

  <div className="digest-wins-grid">
    <div>MCP 服务器可以通过配置中的 <code>alwaysLoad: true</code> 选择退出工具搜索延迟加载，使该服务器的所有工具始终可用</div>
    <div>新增 <code>claude plugin prune</code> 移除孤立的自动安装插件依赖，<code>plugin uninstall --prune</code> 支持级联卸载</div>
    <div><code>/skills</code> 现在带有输入筛选搜索框，可在长列表中无需滚动即可找到技能</div>
    <div><code>PostToolUse</code> 钩子现在可以通过 <code>hookSpecificOutput.updatedToolOutput</code> 替换任何工具的输出，不仅限于 MCP 工具</div>
    <div>新增 <a href="/docs/en/ultrareview"><code>claude ultrareview</code></a> 子命令，可从 CI 或脚本中非交互式运行 <code>/ultrareview</code>：将发现的问题打印到标准输出（<code>--json</code> 输出原始数据），完成时退出码为 0，失败时为 1</div>
    <div><code>--dangerously-skip-permissions</code> 现在绕过对 <code>.claude/</code>、<code>.git/</code>、<code>.vscode/</code>、shell 配置文件及其他受保护路径的写入提示，同时危险的删除命令仍会提示以确保安全</div>
    <div>当 <code>ANTHROPIC\_BASE\_URL</code> 指向兼容 Anthropic 的网关时，<code>/model</code> 选择器可以列出网关 <code>/v1/models</code> 端点的模型；自 v2.1.129 起通过 <code>CLAUDE\_CODE\_ENABLE\_GATEWAY\_MODEL\_DISCOVERY=1</code> 启用</div>
    <div>启动期间遇到临时错误的 MCP 服务器现在会自动重试最多 3 次，而不是保持断开连接</div>
    <div><code>ANTHROPIC\_BEDROCK\_SERVICE\_TIER</code> 选择 Bedrock 服务层级：<code>default</code>、<code>flex</code> 或 <code>priority</code></div>
    <div><code>/terminal-setup</code> 启用 iTerm2 的剪贴板访问设置，使 <code>/copy</code> 可用，包括在 tmux 中</div>
    <div>Vertex AI 现在支持基于 X.509 证书的工作负载身份联合（mTLS ADC）</div>
    <div>重大内存泄漏修复：包含大量图片的会话、在大型对话历史中使用 <code>/usage</code>，以及长时间运行但无进度事件的工具</div>
  </div>
</div>
