  <div className="digest-wins-grid">
    <div>聚焦视图：在无闪烁模式下按 <code>Ctrl+O</code> 可将视图折叠为你的上一条提示词、带差异统计的单行工具摘要，以及 Claude 的最终回复</div>
    <div>登录界面新增引导式 <a href="/docs/en/amazon-bedrock">Bedrock</a> 和 <a href="/docs/en/google-vertex-ai">Vertex AI</a> 设置向导：选择"第三方平台"即可获得分步认证、区域选择、凭据检查和模型固定指引</div>
    <div><code>/agents</code> 采用标签页布局：运行中标签页显示活跃的子代理并带有 <code>● N running</code> 计数，库标签页新增运行代理和查看运行实例操作</div>
    <div>API 密钥、Bedrock、Vertex、Foundry、Team 和 Enterprise 用户的默认努力级别现为 <code>high</code>（通过 <code>/effort</code> 控制）</div>
    <div><code>/cost</code> 为订阅用户显示按模型和缓存命中率的详细分解</div>
    <div><code>/release-notes</code> 现在是交互式版本选择器</div>
    <div>状态栏：新增 <code>refreshInterval</code> 设置可每 N 秒重新运行命令，JSON 输入中新增 <code>workspace.git\_worktree</code></div>
    <div><code>CLAUDE\_CODE\_PERFORCE\_MODE</code>：Edit/Write 在只读文件上失败时会提示 <code>p4 edit</code> 而非静默覆盖</div>
    <div>操作系统 CA 证书存储现在默认受信任，企业 TLS 代理无需额外配置即可工作（设置 <code>CLAUDE\_CODE\_CERT\_STORE=bundled</code> 可取消）</div>
    <div>Amazon Bedrock 由 Mantle 提供支持：设置 <code>CLAUDE\_CODE\_USE\_MANTLE=1</code></div>
    <div>强化 Bash 工具权限：反斜杠转义的标志、环境变量前缀、<code>/dev/tcp</code> 重定向和复合命令现在会正确提示</div>
    <div><code>UserPromptSubmit</code> 钩子可通过 <code>hookSpecificOutput.sessionTitle</code> 设置会话标题</div>
