<div className="digest-wins">
  <p className="digest-wins-title">其他改进</p>

  <div className="digest-wins-grid">
    <div>新增 <code>worktree.baseRef</code> 设置（<code>fresh</code> | <code>head</code>），控制 <code>--worktree</code>、<code>EnterWorktree</code> 工具和代理隔离工作树是从远程默认分支还是本地 <code>HEAD</code> 创建分支；默认值 <code>fresh</code> 确保未推送的提交不会进入新工作树</div>
    <div>新增 <code>settings.autoMode.hard\_deny</code> 规则，在自动模式下无条件阻止匹配的操作，无论是否有允许例外——适用于即使在更宽泛的允许规则下也不应自动执行的操作</div>
    <div>钩子现在通过 `effort.level` JSON 输入字段和 `$CLAUDE_EFFORT` 环境变量接收当前的 effort 级别，Bash 工具命令也可以读取 <code>\$CLAUDE\_EFFORT</code></div>
    <div><code>CLAUDE\_CODE\_DISABLE\_ALTERNATE\_SCREEN=1</code> 可退出全屏备用屏幕渲染器，将对话保留在终端的原生滚动缓冲区中</div>
    <div><code>CLAUDE\_CODE\_PACKAGE\_MANAGER\_AUTO\_UPDATE</code> 允许 Homebrew 或 WinGet 安装在后台运行升级并提示重启</div>
    <div><code>CLAUDE\_CODE\_SESSION\_ID</code> 现已包含在 Bash 工具子进程环境中，与传递给钩子的 <code>session\_id</code> 一致</div>
    <div><code>/mcp</code> 现在显示已连接服务器的工具数量，并标记连接时工具数为 0 的服务器</div>
    <div><code>--channels</code> 现在支持控制台（API 密钥）认证</div>
    <div>子进程（如 Bash、钩子、MCP 和 LSP）不再继承 <code>OTEL\_\*</code> 环境变量，因此通过 Bash 工具运行的使用 OTEL 检测的应用不再连接到 CLI 自身的 OTLP 端点</div>
    <div>子代理进度摘要现在命中提示词缓存，<code>cache\_creation</code> token 成本降低约 3 倍</div>
    <div>多项 OAuth 和凭据可靠性修复：并行会话不再因刷新 token 竞争而在 401 处停滞，MCP OAuth 刷新 token 不再因多个服务器并发刷新而丢失，并修复了罕见的由并发凭据写入引起的登录循环</div>
    <div>新增 <code>parentSettingsBehavior</code> 管理员密钥，允许管理员将 SDK <code>managedSettings</code> 纳入策略合并</div>
  </div>
</div>
