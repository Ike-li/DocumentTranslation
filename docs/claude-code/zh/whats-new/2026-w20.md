  <p className="digest-feature-lede">设定一个完成条件，Claude 会跨多轮持续向它推进，无需你每一步都给出提示。每轮结束后，一个快速模型会检查条件是否已成立；若没有，Claude 会再启动一轮，而不是把控制权交回给你。适合具有可验证终止状态的大型工作，例如把一个模块迁移到所有调用点都能编译并通过测试。条件满足后目标会自动清除；该功能在交互模式、<code>-p</code> 与 Remote Control 下都可用。</p>

  <div className="digest-feature-header">
    <span className="digest-feature-title">Opus 4.7 上的 Fast 模式</span>
    <span className="digest-feature-pill">研究预览</span>

  <p className="digest-feature-lede"><code>/fast</code> 现在默认运行在 Opus 4.7 而不是 Opus 4.6 上。Fast 模式是一种高速 Opus 配置：保持相同的模型质量，速度提升约 2.5 倍，但每 token 成本更高，适合快速迭代与实时调试。定价保持不变，仍为每 MTok $30/$150，与 Opus 4.6 fast 模式相同。要把 fast 模式固定在 Opus 4.6，可设置 <code>CLAUDE\_CODE\_OPUS\_4\_6\_FAST\_MODE\_OVERRIDE=1</code>。</p>

  
    <img className="w-full" src="https://mintcdn.com/claude-code/ITvjicPxe1SM3GX7/images/whats-new/fast-mode-opus-47.png?fit=max&auto=format&n=ITvjicPxe1SM3GX7&q=85&s=6b6d92f7748ce5328a1ee9a269fb1a87" alt="The Claude Code model picker showing Opus 4.7 Fast 1M as the default with the Fast toggle on" width="3840" height="2160" data-path="images/whats-new/fast-mode-opus-47.png" />
  

  <p className="digest-feature-try">切换 fast 模式，现在跑在 Opus 4.7 上：</p>

  ```text Claude Code
  > /fast
  ```

<div className="digest-wins">
  <p className="digest-wins-title">其他亮点</p>

  <div className="digest-wins-grid">
    <div><code>claude agents</code> 新增了一系列派发标志（<code>--add-dir</code>、<code>--settings</code>、<code>--mcp-config</code>、<code>--plugin-dir</code>、<code>--permission-mode</code>、<code>--model</code>、<code>--effort</code>、<code>--dangerously-skip-permissions</code>）来配置后台会话，<code>claude agents --cwd &lt;path></code> 把会话列表限定在某个目录</div>
    <div>新增的钩子 <code>args: string\[]</code> 执行形式直接生成命令而不经过 shell，因此路径占位符无需引号</div>
    <div><code>PostToolUse</code> 钩子的新 <code>continueOnBlock</code> 配置项会把钩子的拒绝原因反馈给 Claude 并继续当前回合，而不是直接结束</div>
    <div>钩子 JSON 输出新增 <code>terminalSequence</code> 字段，使钩子无需控制终端就能发出桌面通知、修改窗口标题与发出蜂鸣</div>
    <div>Rewind 菜单新增 "Summarize up to here"，在保留最近回合的同时压缩较早的上下文</div>
    <div>当设置了 <code>ANTHROPIC\_API\_KEY</code>、<code>apiKeyHelper</code> 或 <code>ANTHROPIC\_AUTH\_TOKEN</code> 时，即便同时有 Claude.ai 登录，Remote Control、<code>/schedule</code>、Claude.ai MCP connector 与通知偏好也会被禁用；要使用这些功能，请取消设置 API 密钥</div>
    <div>MCP stdio 服务器现在会在环境中收到 <code>CLAUDE\_PROJECT\_DIR</code>，与钩子保持一致；插件配置可以在命令中引用 <code>\${"{"}CLAUDE\_PROJECT\_DIR{"}"}</code></div>
    <div><code>claude plugin details &lt;name></code> 显示插件的组件清单与每会话预估 token 成本，<code>/plugin</code> 详情面板现在也会列出插件提供的 LSP 服务器</div>
    <div>根级带有 <code>SKILL.md</code> 且没有 <code>skills/</code> 子目录的插件，现在会作为 skill 暴露</div>
    <div><code>/feedback</code> 现在可以包含最近 24 小时或 7 天的会话，便于反馈跨当前会话的问题</div>
    <div>Agent 工具的 <code>subagent\_type</code> 现在以大小写与分隔符不敏感的方式匹配，例如 <code>"Code Reviewer"</code> 解析为 <code>code-reviewer</code></div>
  </div>
</div>
