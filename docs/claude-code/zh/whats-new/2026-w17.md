<div className="digest-wins">
  <p className="digest-wins-title">其他改进</p>

  <div className="digest-wins-grid">
    <div><a href="/docs/en/interactive-mode#vim-editor-mode">Vim 可视模式</a>：在提示词输入中按 <code>v</code> 进行字符选择，或按 <code>V</code> 进行行选择，支持操作符和视觉反馈</div>
    <div>钩子现在可以通过 <a href="/docs/en/hooks#mcp-tool-hook-fields"><code>type: "mcp\_tool"</code></a> 直接调用 MCP 工具，无需生成进程即可连接已有的服务器</div>
    <div><code>/cost</code> 和 <code>/stats</code> 已合并为 <a href="/docs/en/commands"><code>/usage</code></a>；旧名称仍可作为快捷方式，打开相应标签页</div>
    <div><code>/config</code> 的更改（主题、编辑器模式、详细输出等）现在会持久化到 <code>\~/.claude/settings.json</code>，并遵循与其他<a href="/docs/en/settings">设置</a>相同的项目/本地/策略优先级</div>
    <div><a href="/docs/en/sub-agents#fork-the-current-conversation">分叉子代理</a>可通过 <code>CLAUDE\_CODE\_FORK\_SUBAGENT=1</code> 在外部构建中启用：分叉会继承完整的会话上下文，而不是从头开始</div>
    <div>Pro 和 Max 订阅用户在 Opus 4.6 和 Sonnet 4.6 上的默认<a href="/docs/en/model-config#adjust-effort-level">努力级别</a>现在为 <code>high</code>（之前为 <code>medium</code>）</div>
    <div>原生 macOS 和 Linux 构建将 <code>Glob</code> 和 <code>Grep</code> 工具替换为通过 Bash 可用的嵌入式 <code>bfs</code> 和 <code>ugrep</code>，无需单独的工具往返即可实现更快的搜索</div>
    <div><code>--from-pr</code> 现在除 github.com 外，还接受 GitLab 合并请求、Bitbucket 拉取请求和 GitHub Enterprise PR URL</div>
    <div>自动模式：在 <a href="/docs/en/auto-mode-config"><code>autoMode.allow</code>、<code>soft\_deny</code> 或 <code>environment</code></a> 中包含 <code>"\$defaults"</code>，可在内置列表旁添加自定义规则，而不是替换它</div>
    <div>新增 <a href="/docs/en/plugin-dependencies#tag-plugin-releases-for-version-resolution"><code>claude plugin tag</code></a> 命令，可为插件创建带有版本验证的发布 git 标签</div>
    <div>Opus 4.7 会话现在根据模型原生 1M 上下文窗口计算，修复了 <code>/context</code> 百分比虚高和过早自动压缩的问题</div>
    <div>大型会话的 <code>/resume</code> 速度提升高达 67%，并可在重新读取前提供过时大型会话的摘要</div>
  </div>
</div>
