# CLI 参考

> Claude Code 命令行界面的完整参考，包括命令和标志。

## CLI 命令

您可以使用以下命令启动会话、管道传输内容、恢复对话以及管理更新：

| 命令                            | 描述                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | 示例                                                        |
| :------------------------------ | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :---------------------------------------------------------- |
| `claude`                        | 启动交互式会话                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           | `claude`                                                    |
| `claude "query"`                | 启动带有初始提示词的交互式会话                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           | `claude "explain this project"`                             |
| `claude -p "query"`             | 通过 SDK 查询，然后退出                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  | `claude -p "explain this function"`                         |
| `cat file \| claude -p "query"` | 处理管道输入内容                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | `cat logs.txt \| claude -p "explain"`                       |
| `claude -c`                     | 在当前目录中继续最近的对话                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | `claude -c`                                                 |
| `claude -c -p "query"`          | 通过 SDK 继续                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            | `claude -c -p "Check for type errors"`                      |
| `claude -r "<session>" "query"` | 通过 ID 或名称恢复会话                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   | `claude -r "auth-refactor" "Finish this PR"`                |
| `claude update`                 | 更新到最新版本                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           | `claude update`                                             |
| `claude install [version]`      | 安装或重新安装原生二进制文件。接受像 `2.1.118` 这样的版本号，或 `stable` 或 `latest`。参见 [安装特定版本](/en/setup#install-a-specific-version)                                                                                                                                                                                                                                                                                                                                                                                                            | `claude install stable`                                     |
| `claude auth login`             | 登录到您的 Anthropic 账户。使用 `--email` 预填充您的邮箱地址，`--sso` 强制 SSO 认证，`--console` 使用 Anthropic Console 登录以进行 API 使用计费，而不是 Claude 订阅                                                                                                                                                                                                                                                                                                                                                                                       | `claude auth login --console`                               |
| `claude auth logout`            | 从您的 Anthropic 账户注销                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                | `claude auth logout`                                        |
| `claude auth status`            | 以 JSON 格式显示认证状态。使用 `--text` 获取人类可读输出。如果已登录则以代码 0 退出，未登录则为 1                                                                                                                                                                                                                                                                                                                                                                                                                                                          | `claude auth status`                                        |
| `claude agents`                 | 打开 [代理视图](/en/agent-view) 以监控和调度并行的后台会话。使用 `--cwd <path>` 仅显示在该目录下启动的会话，或使用 `--json` 将活动会话打印为 JSON 数组以便脚本使用。传递 `--permission-mode`、`--model`、`--effort` 或 `--agent` 来设置[调度会话的默认值](/en/agent-view#permission-mode-model-and-effort)。接受类似顶级 `claude` 命令的 `--settings`、`--add-dir`、`--plugin-dir` 和 `--mcp-config`。打开代理视图需要一个交互式终端 | `claude agents --json`                                      |
| `claude attach <id>`            | 在此终端连接到一个[后台会话](/en/agent-view#manage-sessions-from-the-shell)                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | `claude attach 7c5dcf5d`                                    |
| `claude auto-mode defaults`     | 以 JSON 格式打印内置的[自动模式](/en/permission-modes#eliminate-prompts-with-auto-mode)分类器规则。使用 `claude auto-mode config` 查看应用设置后的有效配置                                                                                                                                                                                                                                                                                                                                                                                                | `claude auto-mode defaults > rules.json`                    |
| `claude daemon status`          | 打印后台会话[监督器](/en/agent-view#the-supervisor-process)的状态、版本、套接字目录和工作进程数量，用于诊断。如果监督器未运行，则以代码 1 退出                                                                                                                                                                                                                                                                                                                                                                                                             | `claude daemon status`                                      |
| `claude logs <id>`              | 打印来自[后台会话](/en/agent-view#manage-sessions-from-the-shell)的最近输出                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | `claude logs 7c5dcf5d`                                      |
| `claude mcp`                    | 配置模型上下文协议（MCP）服务器                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          | 参见 [Claude Code MCP 文档](/en/mcp)。                       |
| `claude plugin`                 | 管理 Claude Code [插件](/en/plugins)。别名：`claude plugins`。参见[插件参考](/en/plugins-reference#cli-commands-reference)获取子命令                                                                                                                                                                                                                                                                                                                                                                                                                       | `claude plugin install code-review@claude-plugins-official` |
| `claude project purge [path]`   | 删除项目的所有本地 Claude Code 状态：记录、任务列表、调试日志、文件编辑历史、提示词历史行以及 `~/.claude.json` 中的项目条目。省略 `[path]` 从交互式列表中选择。标志：`--dry-run` 进行预览，`-y`/`--yes` 跳过确认，`-i`/`--interactive` 逐项确认，`--all` 适用于所有项目。参见[清除本地数据](/en/claude-directory#clear-local-data)                                                                                                                                                                                                     | `claude project purge ~/work/repo --dry-run`                |
| `claude remote-control`         | 启动一个[远程控制](/en/remote-control)服务器，以便从 Claude.ai 或 Claude 应用控制 Claude Code。以服务器模式运行（无本地交互式会话）。参见[服务器模式标志](/en/remote-control#start-a-remote-control-session)                                                                                                                                                                                                                                                                                                                                               | `claude remote-control --name "My Project"`                 |
| `claude respawn <id>`           | 重启一个[后台会话](/en/agent-view#manage-sessions-from-the-shell)，无论是运行中还是已停止的，其对话内容将保持不变。使用 `--all` 重启所有正在运行的会话，例如，以使用更新后的 Claude Code 二进制文件                                                                                                                                                                                                                                                                                                                                                      | `claude respawn 7c5dcf5d`                                   |
| `claude rm <id>`                | 从列表中移除一个[后台会话](/en/agent-view#manage-sessions-from-the-shell)。对话记录会保留在您的本地机器上，可通过 `claude --resume` 访问                                                                                                                                                                                                                                                                                                                                                                                                                   | `claude rm 7c5dcf5d`                                        |
| `claude setup-token`            | 为 CI 和脚本生成一个长期有效的 OAuth 令牌。将令牌打印到终端而不保存它。需要 Claude 订阅。参见[生成长期令牌](/en/authentication#generate-a-long-lived-token)                                                                                                                                                                                                                                                                                                                                                                                              | `claude setup-token`                                        |
| `claude stop <id>`              | 停止一个[后台会话](/en/agent-view#manage-sessions-from-the-shell)。也接受 `claude kill`                                                                                                                                                                                                                                                                                                                                                                                                                                                                  | `claude stop 7c5dcf5d`                                      |
| `claude ultrareview [target]`   | 非交互式运行 [ultrareview](/en/ultrareview#run-ultrareview-non-interactively)。将发现结果打印到标准输出，成功时以代码 0 退出，失败时以代码 1 退出。使用 `--json` 获取原始负载，`--timeout <minutes>` 覆盖默认的 30 分钟超时                                                                                                                                                                                                                                                                                                                                | `claude ultrareview 1234 --json`                            |

如果您输错了一个子命令，Claude Code 会建议最接近的匹配项并退出，而不会启动会话。例如，`claude udpate` 会打印 `Did you mean claude update?`。
