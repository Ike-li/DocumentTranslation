# 命令

> Claude Code 中可用命令的完整参考，包括内置命令和捆绑技能。

命令在会话内部控制 Claude Code。它们提供了快速切换模型、管理权限、清除上下文、运行工作流等方法。

输入 `/` 可查看所有可用命令，或输入 `/` 后跟字母进行过滤。

命令仅在消息开头才会被识别。命令名称后的文本将作为参数传递给它。

## 典型工作流程中的命令

大多数命令在会话的特定阶段有用，从设置项目到交付变更。

**仓库中的首次会话。** 运行 `/init` 生成一个起始的 `CLAUDE.md`，然后使用 `/memory` 进行细化。使用 `/mcp` 和 `/agents` 设置项目所需的任何服务器或子代理，并使用 `/permissions` 设置您想要的审批规则。

**任务执行期间。** `/plan` 在进行重大变更前切换到规划模式。`/model` 和 `/effort` 调整您投入的推理量。当对话变长时，`/context` 显示窗口的走向，`/compact` 将其总结；使用 `/btw` 进行快速旁注，以免膨胀历史记录。

**并行执行工作。** `/agents` 打开 Claude 可以委派侧任务的[子代理](/zh/sub-agents)管理器，`/tasks` 列出当前会话中后台运行的内容。`/background` 将整个会话分离，使其作为[后台代理](/zh/agent-view)继续运行，并释放您的终端。对于跨代码库的大型变更，`/batch` 将其分解为独立单元并在各自的[工作树](/zh/worktrees)中运行。有关这些方法如何关联，请参阅[并行运行代理](/zh/agents)。

**交付之前。** `/diff` 显示变更内容，`/code-review` 检查差异中的正确性错误和可清理项，并可通过 `--fix` 应用发现，`/review` 或 `/security-review` 提供更深入的只读审查。`/code-review ultra` 在云端运行多代理审查。

**会话之间。** `/clear` 在保持项目记忆的同时开始新任务。`/resume` 和 `/branch` 让您返回或分叉之前的对话。`/teleport` 将网络会话拉入此终端，`/remote-control` 允许您从另一台设备继续此本地会话。

**出现问题时。** `/rewind` 将代码和对话回滚到检查点，或总结对话的一部分。`/doctor` 和 `/debug` 诊断安装和运行时问题，`/feedback` 报告附带会话上下文的错误。

## 所有命令

下表列出了 Claude Code 中包含的所有命令。大多数是内置命令，其行为编码在 CLI 中。两种条目被特别标记：

* **[技能](/zh/skills#bundled-skills)**：一个捆绑的技能。它的工作方式与您自己编写的技能类似：一个传递给 Claude 的提示词，Claude 也可以在相关时自动调用它。
* **[工作流](/zh/workflows#bundled-workflows)**：一个捆绑的[动态工作流](/zh/workflows)，将工作分发到多个子代理并在后台运行。

要添加您自己的命令，请参阅[技能](/zh/skills)。

在下表中，`<arg>` 表示必需参数，`[arg]` 表示可选参数。

  并非每个命令都会对所有用户显示。可用性取决于您的平台、计划和环境。例如，`/desktop` 仅在使用 Claude 订阅登录的 macOS 和 Windows 上显示，而 `/upgrade` 仅在 Pro 和 Max 计划上显示。

## MCP 提示词

MCP服务器可以暴露显示为命令的提示词。它们使用 `/mcp__<服务器名>__<提示词名>` 格式，并从连接的服务器动态发现。有关详情，请参见[MCP提示词](/zh/mcp#use-mcp-prompts-as-commands)。
