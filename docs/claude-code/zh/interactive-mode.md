## 键盘快捷键

键盘快捷键可能因平台和终端而异。在[全屏渲染](/zh/fullscreen)中，在记录查看器中按 `?` 可查看可用快捷键。

**macOS 用户**：Option/Alt 键快捷键（`Alt+B`、`Alt+F`、`Alt+Y`、`Alt+M`、`Alt+P`）需要在终端中将 Option 配置为 Meta：

* **iTerm2**：Settings → Profiles → Keys → General → 将 Left/Right Option key 设为 "Esc+"
* **Apple Terminal**：Settings → Profiles → Keyboard → 勾选 "Use Option as Meta Key"
* **VS Code**：在 VS Code 设置中设 `"terminal.integrated.macOptionIsMeta": true`

详见[终端配置](/zh/terminal-config)。

## 命令历史

Claude Code 为当前会话维护命令历史：

* 输入历史按工作目录存储
* 运行 `/clear` 开始新会话时输入历史会重置。之前的会话对话会被保留，可以恢复
* 连续两次提交相同的提示词只记录一个历史条目，因此按 Up 会跳到上一个不同的提示词
* 使用上/下方向键导航（参见上方键盘快捷键）
* **注意**：历史扩展（`!`）默认禁用

### 使用 Ctrl+R 反向搜索

按 `Ctrl+R` 交互式搜索命令历史：

1. **开始搜索**：按 `Ctrl+R` 激活反向历史搜索
2. **输入查询**：输入文本搜索之前的命令。搜索词在匹配结果中高亮显示
3. **导航匹配**：再次按 `Ctrl+R` 循环切换更早的匹配项
4. **更改范围**：搜索默认为所有项目的提示词。按 `Ctrl+S` 在此会话、此项目和所有项目之间循环切换范围
5. **接受匹配**：
   * 按 `Tab` 或 `Esc` 接受当前匹配并继续编辑
   * 按 `Enter` 接受并立即执行命令
6. **取消搜索**：
   * 按 `Ctrl+C` 取消并恢复原始输入
   * 在空搜索中按 `Backspace` 取消

搜索显示匹配的命令，搜索词高亮显示，以便你可以找到并重用之前的输入。

## 后台 bash 命令

Claude Code 支持在后台运行 bash 命令，允许你在长时间运行的进程执行时继续工作。

### 后台运行的工作原理

当 Claude Code 在后台运行命令时，它会异步运行命令并立即返回后台任务 ID。Claude Code 可以在命令继续在后台执行的同时响应新的提示词。

要在后台运行命令，你可以：

* 提示 Claude Code 在后台运行命令
* 按 Ctrl+B 将常规 Bash 工具调用移到后台。（Tmux 用户由于 tmux 的前缀键需要按两次 Ctrl+B。）

**关键功能：**

* 输出写入文件，Claude 可以使用 Read 工具检索
* 后台任务有唯一 ID 用于跟踪和输出检索
* Claude Code 退出时后台任务自动清理
* 如果输出超过 5GB，后台任务自动终止，stderr 中有说明原因的注释

要禁用所有后台任务功能，将环境变量 `CLAUDE_CODE_DISABLE_BACKGROUND_TASKS` 设为 `1`。详见[环境变量](/zh/env-vars)。

**常见的后台命令：**

* 构建工具（webpack、vite、make）
* 包管理器（npm、yarn、pnpm）
* 测试运行器（jest、pytest）
* 开发服务器
* 长时间运行的进程（docker、terraform）

### 使用 `!` 前缀的 Shell 模式

通过在输入前加 `!` 直接运行 shell 命令，无需经过 Claude：

```bash
! npm test
! git status
! ls -la
```

Shell 模式：

* 将命令及其输出添加到对话上下文
* 显示实时进度和输出
* 支持相同的 `Ctrl+B` 后台运行长时间命令
* 无需 Claude 解释或批准命令
* 支持基于历史的自动补全：输入部分命令并按 **Tab** 从当前项目中之前的 `!` 命令补全
* 使用 `Escape`、`Backspace` 或 `Ctrl+U` 在空提示词下退出
* 将以 `!` 开头的文本粘贴到空提示词中会自动进入 shell 模式，与输入 `!` 行为一致

这对于在保持对话上下文的同时快速执行 shell 操作很有用。

## 提示词建议

当你首次打开会话时，提示词输入中会出现一个灰色的示例命令来帮助你入门。Claude Code 从项目的 git 历史中选取，因此它反映了你最近一直在处理的文件。

Claude 回复后，建议会继续基于你的对话历史出现，例如多部分请求中的后续步骤或工作流的自然延续。

* 按 **Tab** 或 **右方向键** 将建议放入提示词输入，然后按 **Enter** 提交
* 开始输入即可取消建议

建议作为后台请求运行，复用父对话的提示词缓存，因此额外成本很小。当缓存较冷时，Claude Code 会跳过建议生成以避免不必要的成本。

建议在对话第一轮之后和计划模式中自动跳过。在打印模式下默认关闭。传递 [`--prompt-suggestions`](/zh/cli-reference#cli-flags) 配合 `--output-format stream-json --verbose` 可在每轮之后发出 `prompt_suggestion` 消息。

要完全禁用提示词建议，设置环境变量或在 `/config` 中切换设置：

```bash
export CLAUDE_CODE_ENABLE_PROMPT_SUGGESTION=false
```

## 使用 /btw 的附带问题

使用 `/btw` 快速提问与当前工作相关的问题，而不添加到对话历史中。当你想要快速回答但不想使主上下文变得混乱或打断 Claude 的长时间运行任务时很有用。

```
/btw what was the name of that config file again?
```

附带问题对当前对话有完全可见性，因此你可以询问 Claude 已读取的代码、之前做出的决定或会话中的任何其他内容。问题和答案是临时的：它们出现在可关闭的叠加层中，永远不会进入对话历史。

* **Claude 工作时可用**：即使 Claude 正在处理回复，你也可以运行 `/btw`。附带问题独立运行，不会中断主回合。
* **无工具访问**：附带问题仅从已有上下文中回答。Claude 在回答附带问题时无法读取文件、运行命令或搜索。
* **单次回复**：叠加层中没有后续轮次。要继续该线程，用 `f` 将其分叉到自己的会话中。
* **低成本**：附带问题复用父对话的提示词缓存，因此额外成本很小。

答案出现后，叠加层接受以下按键。来自同一会话的较早附带问题作为暗淡列表显示在当前答案上方；它们不在对话历史中，但在叠加层中保持可见直到你清除。

| 按键                       | 动作                                                                                                                                                                                                                                                                    |
| :------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `Space`、`Enter`、`Escape` | 关闭答案并返回提示词                                                                                                                                                                                                                                                     |
| `Up` / `Down`              | 滚动答案                                                                                                                                                                                                                                                                 |
| `f`                        | 分叉到新会话。分叉继承父对话加上此问答作为真正的记录轮次，因此你可以继续并拥有完整的工具访问权限。原始会话保留在 [`/resume`](/zh/commands) 中。仅在本地会话中可用                                                                                                          |
| `x`                        | 清除当前答案上方显示的较早 `/btw` 交流列表                                                                                                                                                                                                                                |

`/btw` 是[子代理](/zh/sub-agents)的逆向：它能看到你的完整对话但没有工具，而子代理有完整工具但从空上下文开始。使用 `/btw` 询问 Claude 已经从本次会话中知道的内容；使用子代理去发现新信息。

## 任务列表

当处理复杂的多步骤工作时，Claude 会创建任务列表来跟踪进度。任务显示在终端的状态区域中，带有指示器显示待处理、进行中或已完成。

* 按 `Ctrl+T` 切换任务列表视图。显示一次最多 5 个任务
* 要查看所有任务或清除它们，直接问 Claude："show me all tasks" 或 "clear all tasks"
* 任务在上下文压缩后持续存在，帮助 Claude 在大型项目中保持组织性
* 要在会话间共享任务列表，设置 `CLAUDE_CODE_TASK_LIST_ID` 以在 `~/.claude/tasks/` 中使用命名目录：`CLAUDE_CODE_TASK_LIST_ID=my-project claude`

## 会话回顾

当你离开终端后返回时，Claude Code 会显示会话到目前为止发生的事情的单行回顾。回顾在最后一次完成的轮次过去至少三分钟且终端失去焦点后在后台生成一次，因此当你切换回来时已准备好。回顾仅在会话至少有三轮后出现，且不会连续出现两次。

运行 `/recap` 可按需生成摘要。要关闭自动回顾，打开 `/config` 并禁用 **Session recap**。

会话回顾默认对每个计划和提供商启用。在非交互模式下始终跳过回顾。

## PR 审查状态

当在有打开的拉取请求的分支上工作时，Claude Code 在页脚中显示可点击的 PR 链接（例如 "PR #446"）。链接有彩色下划线表示审查状态：

* 绿色：已批准
* 黄色：等待审查
* 红色：需要更改
* 灰色：草稿

当拉取请求合并或关闭后，徽章消失。`Cmd+click`（Mac）或 `Ctrl+click`（Windows/Linux）链接可在浏览器中打开拉取请求。状态每 60 秒刷新一次，并在会话中运行 `gh pr` 或 `git push` 命令后立即刷新。

PR 状态需要安装并认证 `gh` CLI（`gh auth login`）。
